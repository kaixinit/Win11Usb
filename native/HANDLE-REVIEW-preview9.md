# preview.9：格式化、拆分、复制、校验的句柄检查

日期：2026-10-22。保留界面、整盘确认和六阶段制作规则。当前候选为 `Win11Usb-NativeReview-v0.2.0-preview.9.exe`；GitHub beta.3 未更换。

## 发现与修正

1. 命令执行器原来在结束 Job 后仅等待主进程最多 2 秒，未检查等待结果；异常路径还把 Job 留给后端析构关闭。现在所有路径均由作用域关闭 Job，运行期间与结束前记录可查询的 Job 进程句柄；结束命令后同时核验主进程、已记录进程的退出信号及 Job 活动数为零，最多等待 10 秒。未确认退出则停止后续制作。不会把 Job 计数为零或 Job 句柄信号本身当作进程 I/O 已完成的唯一依据。
2. CopyFileEx 的进度回调原来直接调用 C++ 回调。回调异常可能越过系统调用的收尾；现在回调捕获异常、返回 PROGRESS_CANCEL，等 CopyFileEx 返回后才重新抛出。普通取消仍按原有方式处理。
3. 任务新增工作线程内的 Finish 作用域收尾：成功、失败、取消以及错误报告自身异常时，均在返回 UI 前释放 SWM、FAT32 helper、ISO 文件引用、VirtDisk 控制句柄和任务目录引用。不会等待 UI 消息处理或后端析构。保留日志与失败 SWM；成功时选择保留 ISO 挂载仍有效。
4. SWM 固定引用改用复制/校验共用的只读打开规则，核对普通文件类型与大小；整组获取失败时释放先前文件。完整内容校验通过后立即解除 SWM 固定引用，之后才允许清理。
5. 最后一次刷新目标卷缓存后显式关闭卷句柄，再进行身份查询；WIMGAPI 元数据缓冲区与卷/设备枚举句柄也加入作用域释放，覆盖异常路径。WIM 句柄禁止复制，避免意外重复关闭。

## 阶段交接核对

| 位置 | 持有与释放顺序 | 验证范围 |
| --- | --- | --- |
| 删除旧布局、建立新分区 | 旧卷锁在删除布局后解除；重建所用整盘句柄在启动 formatter 前关闭；身份查询句柄仅在各自函数内存在 | 源码审查及共享状态机测试，真实控制器待测 |
| FAT32 格式化 | 沿用 preview.8 的共享打开、锁卷前后核验；成功刷新、卸载、解锁、关闭设备后退出；失败进程退出释放 OS 资源 | 148 项文件测试，实际锁卷 IOCTL 使用替身 |
| NTFS 格式化 | GUID 和无交互参数保持；命令结束核验完成才开始文件系统就绪检查、设置卷标和分配盘符 | 参数及就绪状态机测试，真实 NTFS 格式化待测 |
| DISM 拆分 | WIM 元数据读取句柄先关闭；拆分命令返回并完成进程退出核验后，才枚举、固定并检查全部 SWM | 真实合成 WIM/SWM 文件；大 WIM DISM 仍待实测 |
| 复制 | 每个源文件仅在本文件复制期间持有只读引用；CopyFileEx 正常、取消和回调错误返回后再解除引用 | 实际本机文件与独占打开测试 |
| 校验 | 校验前先刷新并关闭卷句柄；每个文件源/目标成对只读打开，比较结束或异常时关闭；最终刷新卷句柄关闭后解除 SWM 引用 | 实际逐块内容比较、损坏与取消测试 |
| 清理和弹出 | SWM 引用解除后再按全部文件的删除句柄清理；USB 弹出先刷新、锁定、卸载、解锁并关闭卷句柄，再请求设备弹出 | 真实 SWM 删除；物理弹出仅审查/流程替身 |
| 失败或取消 | 命令收尾结束后释放 SWM 引用；原有 Abort 仅尝试卸载本任务挂载的 ISO；Finish 解除剩余应用引用 | 真实文件、后代进程与工作目录测试 |

目录在任务期间保持固定是有意的安全措施：防止被改名、替换或通过 junction 重定向。它们位于本机任务目录，并非目标 USB 卷。日志文件保持到 UI 接到结束消息后刷新并关闭，这是保存最终诊断所需的短暂保留。未删除任务日志目录。

## 自动化证据

`native\test.cmd`：596 项主程序断言、148 项普通文件 formatter 断言通过，共 744 项；另验证 formatter 无效定位失败和完整锁定超时返回 32 且标记原样。

- 实际测试程序创建一个后代进程，后代先独占打开文件；在主命令正常退出、返回非零、超时、取消、日志回调异常五种情况下，命令返回后立即独占读/写/删除打开该文件，且检查已观测后代已经退出。日志也能立即独占打开。
- 同一个执行器重复失败后，进程句柄数量不增长。SWM 整组获取中途失败重复 12 次后，句柄数不增长；计数前先预热 Windows 错误资源，文件独占打开检查不等待析构后端。
- 真实 CopyFileEx 复制、取消及回调抛错后，源文件和保留的目标文件可独占打开；实际内容校验的成功、损坏、取消路径也有此检查。
- 真实 SWM 在固定引用持有时不能删除，释放后可清理；文件集成测试加入生产共用的固定引用函数。四条 FAT32/NTFS × 拆分/不拆分成功路径，以及十条失败/取消路径均在后台对象仍存活时检查释放；成功任务目录此时即可改名并恢复。
- Finish 在六阶段各处出错，以及错误报告自身再抛错时，均只执行一次。

## 边界和后续验收

本机没有可清空的 USB，也没有管理员权限。本次没有执行真实设备格式化、真正的 DISM 大 WIM 拆分或固件启动；格式化/弹出在文件集成测试中是替身。现有用户日志证明新分区已通过核验，随后报 FAT32 打开卷错误 32，无法从该日志确定冲突句柄属于哪个进程。preview.8 的修复在本版保留，但仍需实机验证。

Job 查询和句柄测试覆盖本程序可观测的命令进程及后代；不能宣称会释放其他应用、杀毒过滤驱动或系统服务的占用。生产步骤遇到共享冲突、未确认退出或身份变化仍会停止，不通过全局杀进程、关闭安全软件或跳过校验继续。

下一次请仅在已备份并允许清空的测试 U 盘上验收，保留 `session.log`、`fat32format.log`/`format-ntfs.log`、DISM 日志；依次核对格式化、拆分、复制内容校验、SWM 清理及安全弹出。原生版通过目标机完整制作、Defender 动态检查及 UEFI 启动前，不替换 GitHub beta.3 下载。
