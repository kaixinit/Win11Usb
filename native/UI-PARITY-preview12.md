# beta.3 界面与交互恢复：preview.12

日期：2026-10-23。以本地保存的 GitHub beta.3 发布源码、`src/Ui/MainWindow.xaml`、`MessageDialog.xaml`、`FormatDialog.xaml`、`src/Launcher/NativeWindow.cs` 和发布截图为基准。GitHub beta.3 下载未替换。

## 已恢复

- 主窗口默认 840×800，沿用蓝白配色、三行设置、原版字号和间距、圆角按钮、USB 两行选择器、细六阶段导航、4 px 主进度和 2 px 当前文件进度、深色日志、底部信息与播放按钮。完整制作版把诊断导出放入系统菜单；运行时显示原版白底红字“强制结束”。
- 原版 13 个 Material Design Icons Geometry 转为静态 GDI+ 路径，保留实心 ISO、USB、设置、刷新、步骤、日志等图标；USB 保留原来的旋转。原始路径与 Apache 2.0 来源声明保留，运行 EXE 内嵌图标和许可，不读取 XAML、Python 或外部图片。生成器仅供开发时重新生成已提交的头文件。
- 恢复带状态图标、圆角详情卡和明确按钮的原生弹窗。整盘格式化使用红色主按钮和独立警告卡；默认取消；NTFS 兼容性提示保留；详情可选中复制和滚动；成功后显示制作结果。
- ISO 名称按分隔符换行，完整路径保留在悬停提示。设备名称与元数据支持换行，完整信息也有悬停提示。长内容优先增高窗口；受屏幕可用高度限制时保护底部操作与日志区域。
- 原生自绘按钮支持 Enter；FAT32/NTFS 方向键只在文件系统选项之间切换。

## 操作顺序

| 时机 | 行为 / 默认选择 |
| --- | --- |
| 点击开始制作 | 展示目标、ISO、文件系统；默认“返回检查” |
| 只读挂载、识别、预检后 | 展示整盘格式化详情；默认“取消” |
| 拆分、复制、校验 | 自动继续，保留取消、进度和日志；不再增加确认框 |
| 生成过临时 SWM | 询问“清理文件 / 保留文件”；默认清理 |
| USB 弹出 | “安全弹出 / 保持连接”；默认安全弹出 |
| ISO 弹出 | “弹出 ISO / 保留挂载”；默认弹出 |
| 成功 | 显示结果及该次任务的设备、系统、卷标与实际弹出结果 |
| USB 弹出失败 | 保留制作成功状态，显示准确原因与“U 盘尚未弹出”，不统一误称句柄占用 |

完成信息来自工作流显式返回的数据和开始时保存的设备快照，不从刷新后的设备列表或截断日志反推。提示请求使用退出守卫通知工作线程，即使弹窗创建失败，也不会无限等待确认。

## 保留的原生能力

设备身份核验、任务临时目录和 scratch 校验、清盘状态机、FAT32 锁卷与句柄释放、大 WIM 拆分、CopyFileEx 复制、文件内容读回比较、缓存刷新和安全弹出节点选择保持原生实现。`backend.cpp`、`disk_rebuild.cpp`、`postformat.cpp`、`workspace.cpp`、`files.cpp`、`process.cpp`、`wim.cpp`、`eject.cpp` 及 FAT32 工具的制作实现未因界面恢复重写。

保留 preview.10 的 `WS_CLIPCHILDREN`、约 100 ms 消息合并、局部进度失效、日志批量追加、结束前刷新保存；进度失效区域随布局计算，不再使用固定坐标。

两个 EXE 均为 x64 原生 GUI，静态 C++ 运行库，无 CLR 头、无 .NET / WPF / PowerShell / WMI 应用运行时依赖。GDI+ 是 Windows 系统图形 DLL。完整制作继续使用系统 VirtDisk、WIMGAPI、DISM；NTFS 使用系统 format.com。单文件指仅分发一个 EXE，制作时仍创建日志、临时文件并提取独立 FAT32 工具及源码许可。

## 验证范围

- 主测试 782 项断言，普通文件 FAT32 工具测试 148 项，共 930 项通过。包含 FAT32/NTFS × 拆分/不拆分的实际普通文件集成、精确提示顺序、失败/取消、结果字段、句柄与 eject 策略回归。真实分区 IOCTL、格式化设备、DISM 大 WIM 数据生成和 PnP 移除使用测试替身。
- 生产 UI 测试覆盖 5,000 条日志、10,000 次进度；设置区域零重绘；日志完整保存；成功/弹出警告分别显示；默认取消、Enter/Esc、500×400 NTFS 确认框布局。
- 追加验证 Enter/Space、单选框方向键、Tab、720 宽长文件名/长设备信息，以及模拟 144 DPI（150%）的控件边界、页脚不重叠与完整路径提示。测试 EXE 链接与发行只读版相同的资源和系统 Common Controls v6 清单。
- 使用实际只读 EXE 检查主界面、文件名换行、设备下拉、格式化样式、默认取消和 Esc 返回。示例界面不挂载 ISO，不操作磁盘。
- 对最终 EXE 的 PE、导入表、嵌入资源和 Defender 文件扫描结果见同目录 `test-results/preview12`。文件扫描不等于所有环境中的动态检测或真实 U 盘制作验收。

本机测试进程为普通权限，没有可授权清空的测试 U 盘。本轮没有重新格式化实机设备、执行真实大 WIM 拆分、验证 UEFI 引导或执行真实 USB 弹出。preview.9 的 Kingston 全容量 FAT32 制作和内容校验日志证据继续有效；preview.11/12 的安全弹出修复仍需原设备实测。

实现参考：[Microsoft：通过应用清单启用系统视觉样式](https://learn.microsoft.com/en-us/windows/win32/controls/cookbook-overview)。
