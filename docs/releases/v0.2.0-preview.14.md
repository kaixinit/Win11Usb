# Win11Usb v0.2.0-preview.14 · 原生预发布版

用一个 EXE，把 Windows ISO 制作为安装 U 盘。新版改用 **C++ / Win32**，无需安装 **.NET、PowerShell 或 VC++ Redistributable**，保留 beta.3 的单窗口界面和制作顺序。

**[下载 Windows x64 单文件 EXE](https://github.com/kaixinit/Win11Usb/releases/download/v0.2.0-preview.14/Win11Usb-v0.2.0-preview.14-windows-x64.exe)** · [发布页与全部附件](https://github.com/kaixinit/Win11Usb/releases/tag/v0.2.0-preview.14) · [继续下载 beta.3](https://github.com/kaixinit/Win11Usb/releases/tag/v0.1.0-beta.3)

## 这版有什么变化

- **大容量 U 盘，全容量 FAT32。** 重建单个占用整盘可用容量的 FAT32 分区，保留正常对齐开销，不将大盘截成约 32 GB。原来是 NTFS 的 U 盘也可重新制作；这会删除整盘全部分区和文件。
- **大映像自动拆分。** `install.wim` 超过 4,294,967,295 字节时自动拆分为 SWM，无需手动处理；FAT32 和 NTFS 保留相同的拆分规则。
- **单文件免安装，可离线制作。** 运行时不使用 .NET、WPF、PowerShell、WMI/CIM 或脚本启动器；选择本地 ISO 即可开始准备。
- **复制后读回内容。** 核对每个文件的大小，并逐块比较源文件和 U 盘文件内容；检查关键 x64 UEFI 文件。它不是介质坏块或寿命检测。
- **熟悉的界面，更稳定的刷新。** 保留 beta.3 的图标、弹窗、确认顺序和单窗口日志，合并高频进度与日志刷新，减少复制期间闪烁。
- **完成与弹出分别报告。** 修正 USB 存储节点类别识别，安全弹出前核对设备和影响范围；若系统拒绝弹出，保留已完成的制作结果并显示具体原因。

## 使用方法

![原生版制作中界面，只读预览与示例数据](../screenshots/native/running.png)

截图来自实际原生界面的只读预览，使用示例设备与模拟进度，不代表实机写盘或启动结果。

1. 下载 EXE，以管理员权限运行，选择本地 Windows ISO。
2. 选择已备份的写入 U 盘，核对设备型号、整盘容量和磁盘编号；通常优先使用 FAT32。
3. 点击“开始制作”，在最终确认中再次核对目标磁盘。确认后会清除整盘内容。
4. 等待格式化、映像处理、复制与内容校验结束，再按提示选择临时 SWM 清理、U 盘安全弹出和 ISO 弹出。

## 系统范围与许可

面向具备所需系统组件的 Windows 10/11 x64，当前目标为 x64 UEFI。运行仍需要 Windows 自带的 Win32/GDI+、存储驱动、VirtDisk、WIMGAPI；大 WIM 拆分使用 DISM，NTFS 使用系统格式化工具。不承诺任意精简系统或 WinPE 都具备这些组件，也不宣称 Legacy BIOS、ARM64 支持。NTFS 保留“部分 UEFI 固件可能不支持启动”提醒。

自有应用源码使用 MIT 许可。独立 FAT32 工具保留 GPL 源码与声明；界面图标的 Material Design Icons Apache 2.0 声明及静态运行库许可随程序保留，见 [第三方声明](../../THIRD_PARTY_NOTICES.md)。

## 会覆盖 beta.3 吗

**不会。** 原生版采用独立标签 `v0.2.0-preview.14`、独立文件名和独立发布附件；`v0.1.0-beta.3` 的标签和原附件保留。两个单文件程序可以保存在不同文件夹，或保持各自版本文件名并存；只有手动用相同文件名复制到相同位置时，才会发生本地文件替换。两版都操作物理磁盘，请每次核对写入目标。
